# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-09-25

### Added

- Public reference stack: MCP gateway, Artifactory/GitHub/GDrive MCP servers, LangGraph JFrog agent.
- **Agent Safety Kit**: pre-LLM input guard and offline PII scanner.
- Agent **tracking and evaluation** (SQLite local, BigQuery optional), OpenTelemetry hooks, Grafana dashboard.
- **Context optimizer** with protocol-aware trimming presets.
- Documentation layout: root quick start + [doc/howto/QUICKSTART.md](doc/howto/QUICKSTART.md).
- Apache-2.0 license and contributing guide.

### Changed

- Root README rewritten for clarity (SubmitQueue-style overview and doc table).
